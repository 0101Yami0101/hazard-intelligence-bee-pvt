3The law: six frozen choices

From DATA_CONTRACT.md. Changing any of them means rebuilding everything. 🔒 means changing it after a model exists would void every number we've published.

1 · map projection
UTM zone 46N
Raw data comes in degrees, and a degree isn't a fixed distance. In metres, "500 m from a road" is easy. Arunachal spans two zones, but the error is 0.4%.
2 · square size
100 m
30 m = 91 M squares, too slow. 250 m blurs the steep face that actually fails. 100 m = 8.2 M, fits in memory.
3 · starting corner
x 350,000 · y 2,950,000
A round number fixed by hand, not taken from the border file. If the border file changed, a computed corner would shift every square silently.
4 · square ID
row × 100,000 + col
You can decode any ID in your head, so a bad join shows up at once. Try it in section 4.
5 · column names
group_name_unit
soil_bdod_0-5cm_cgcm3. The unit is in the name because a soil density of "107" once fooled us: it is centigrams, not grams.
6 · test blocks
50 km → 5 groups
Fixed seed 42, frozen before any model was trained, with a fingerprint (ce08e9f0124386ac) to prove it. Otherwise you'd pick blocks that flatter the model without noticing.
⚖️ If the doc and the code disagree, the code wins. scripts/build/grid.py is the single source of truth. The doc only explains why.

Every square gets these 34 columns. Hover a chip to read what it means. Most come from just two downloads: the height map and the soil map.

➕ Also on the grid, but not among the 34: HAND and the size of the nearest channel (built later for FloodSense), and the rain index (section 7). The 34 are the landslide model's inputs. Each product reads the columns it needs.

6Three moves turn any shape into a column

Sources come as grids, outlines or lines. Each has its own move to land on the 100 m squares.

🔲 Grid → grid
A coarse grid (soil at 250 m) is spread over the squares it covers. A fine one (height at 30 m) is worked out first, then averaged: slope is worked out at 25 m and then averaged, so steep faces aren't smoothed away.
🧩 Outline → label
A rock map is a set of outlines. Each square asks "which outline am I inside?" and stores that rock's code.
📏 Line → distance
A road, river or fault is a line. Each square stores "how far to the nearest one". This is measured on the full box, so a square near the border still finds a road just across it.

7Rain is special: never copied onto the 100 m squares

Copying rain onto every square would mean 8.2 M squares × 9,555 days = 78 billion numbers, about 12,000 copies of each rain value. So we don't.

The trick: one file, imerg_index.tif, stores for every 100 m square which rain square it sits in. Models join on (rain square, date). It holds the same information with four orders of magnitude less storage.

It's also honest. A 100 m rain map would look sharp and invite people to trust it at 100 m. It's 11 km data.

📚 Rain history
NASA IMERG, ~11 km squares, 2000-06-01 → 2026-07-29, 9,555 days, zero gaps. 892 rain squares cover the state. The whole archive is only 326 MB, and downloading it is a ~2-hour job.
📡 Live rain + 7-day forecast
Open-Meteo, a free weather service, at 219 points about 22 km apart. One fetch feeds both forecasts. Points are spaced that far apart because of the free tier's limits: a budget limit, not a science limit.
🔁 Trap we hit: four days looked like holes in NASA's archive. They were our own bug: the script asked for the wrong file version. Always re-check before calling data missing.

9How the backbone moved to Assam

One switch: REGION=assam. Every script reads it at start-up. With nothing set, everything runs for Arunachal exactly as before.

＝ What stayed the same
  • Projection (UTM 46N), 100 m squares, the ID formula, column names
  • Every fetch and build script: the same code, run with the switch
  • Raw folders (file names carry the region)
  • Arunachal's files and live forecasts: proven unchanged by check_live_unchanged.py
≠ What Assam got of its own
  • Its own corner (160,000 / 2,660,000) and box (6,500 × 4,500 squares)
  • Its own download area (89.5–96.2°E, 24.0–28.2°N)
  • The official Survey of India outline (35 districts), not GADM: 78,424 km² against the official 78,438 km²
  • Its own folders (data/interim/assam/) and its own frozen test blocks
🧩 One lattice. Both corners are whole multiples of 10 km, so where the two boxes overlap, Assam's squares sit exactly on Arunachal's. A river that crosses the border can be stitched square by square.

10Free → Ask → Paid: the data ladder

Every limit belongs to a tier. Never call a Free-tier limit permanent. Say what lifts it.

Free · todayopen satellite and government data
  • an area, days ahead
  • everything on this page
Ask · letters, not moneywhat offices already hold
  • finer and faster
  • gauges, road-block logs, river cross-sections, dam releases
Paid · chosen spotswhat we generate
  • one slope or river reach, hours ahead
  • sensors, drones, LiDAR terrain

The asks that matter most (from GOV_DATA_REQUEST_LIST.md)

GSI
The Landslidedata_1 event table: date, time and rain for each slide. This unlocks when. Ask for it by table and field name.
State PWD · BRO · PMGSY
Road-block logs: dated, located slides. The best realistic source of landslide dates, and what lets us grade the landslide forecast.
IMD
Rain gauge records, hourly. Ground truth for satellite rain on the ridges and at Tawang.
CWC
River cross-sections (to turn a level into a depth and extent) and danger lines for gauges that don't have them.
NHPC · dam operators
Dam release schedules: on a regulated river, a release can matter more than rain.
SDMA · DDMA
Event and damage records: what really happened, to grade both forecasts.
🧭 Standing rule: don't wait for an ask. Derive the missing piece ourselves where we can, and use it as proof of capability. Asks sharpen; they don't block.

11Portals that look closed, but aren't

Several sources first got logged as "blocked, needs a formal request". Each time, the web page lied, not the server.

🔍 The method: read the map viewer's own code for its real data addresses, then ask the server directly what it holds. This matters in the room: if an APSAC scientist says "that layer isn't public", you know how it was reached.

12Checked before trusted: real catches

Rule 3 in action. Each of these would have quietly poisoned a model.

Official flood map on cliffs
70.5% of Bhuvan's "flooded" pixels were on slopes over 15°. It's a rendered picture, smeared at the edges. Declared unusable as truth.
GSI's map came out scrambled
Exported in one big piece, the national susceptibility map matched its own source on only 41% of squares. Fixed by downloading in tiles on the server's own grid, then checking a small tile against a big one.
Landslides outside the state
GSI sends data by map sheet, not by state: 246 of its polygons were in Nagaland and Assam. Filter by state before counting.
One wrong river reading = a "52% flood"
A single bad gauge value looked like a flood. Now a three-pass spike filter cleans readings, and it has found 18 false high-water days.
Soil density of 107
That's centigrams per cm³, i.e. 1.07 g/cm³. Hence the unit in every column name.
Rain "holes" that weren't
Four missing days were our own version bug, not NASA's. Re-check before declaring data missing.
