1The mess: every map is drawn differently

We collect maps from 29 places. Each one was drawn by different people, for different jobs. They don't fit together.

2The graph paper: every square has an address

👆 Tap any square

We cover the whole state with one sheet of graph paper. Then we copy every map onto it.

📏Each square is 100 m × 100 m, about one football pitch
🔢8.2 million squares inside the state
🏠Every square has an address: row × 100,000 + column. Like a house number, you can work out where it is from the number
📌The sheet's corner is nailed to a round number and never moves, even if a source map changes

Real: scripts/build/grid.py · docs/design/DATA_CONTRACT.md

Every map is a different kind of problem. Pick one. Left is what arrives; right is what goes on our paper.

4The prize: one square, all its facts

After lining up, you can point at any one square and read every fact about it, all about the same patch of ground.

Every sheet is the same graph paper, so a pin through one square hits the same spot on all of them.

Real fact names; pretend numbers. The real table has 34 facts per square and 26 years of daily rain per place.

🧠 Why it matters: the model can only learn "steep + weak rock + lots of unusual rain = danger" if all three facts are about the same square. Without lining up, it would be mixing facts from different places, like matching one kid's height with another kid's shoe size.
